About Luclid-ii

Luclid-ii is a Windows-first local AI agent. This browser-powered web adaptation is inspired by the supplied v0.5.7.1 desktop source and keeps the purple retro theme, tabs, GitHub browser, and sample tools.

Privacy: LinkedIn and Google integrations are omitted entirely. The website does not ask for GitHub credentials, read local files, connect to Ollama, or execute system commands. Model weights are downloaded from Hugging Face; chat prompts are processed locally in your browser.

AI model: SmolLM2-135M-Instruct (small and fast, but limited reasoning). WebGPU preferred; WASM fallback. First load requires an internet connection and substantial download.
