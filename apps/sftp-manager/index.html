Help & About

SFTP Manager is a Python/PySide6 desktop application with Paramiko, Docker support, a transfer queue, and activity monitoring.

This web edition is a safe interactive simulation, not a real SFTP client. Choose a file on either side and use Upload or Download. Try creating a folder, inspecting permissions, and viewing Docker status.

Desktop reference: v0.7.5. GitHub links are searched rather than guessed until the actual repository URL is confirmed.
